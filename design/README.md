# Design

Brand and icon assets for the NuxOffice suite.

## Approved visual direction

Calm, minimalist, polished, friendly rounded-square icons with a common construction: soft gradient, subtle layered sheet shape, restrained shadow, a white letter and one simple secondary symbol. No busy highlights, excessive 3D, tiny details or third-party logos.

| App | Color | Letter | Secondary symbol |
|---|---|---|---|
| Cellnux | Emerald green | C | Spreadsheet grid |
| Writenux | Blue | W | Document lines |
| Presentnux | Orange | P | Presentation chart |
| Datanux | Purple | D | Database cylinder |

Cellnux wordmark: `Cell` in dark charcoal, `nux` in green. Tagline: **SPREADSHEETS FOR EVERYONE**.

## Directories

- `brand/` holds the approved reference image (`suite-icons-reference.png`) and, later, brand guidelines and the wordmark. The reference image is a **visual reference only**, not an editable source.
- `icons/` will hold original vector SVG sources and exports.

## Deliverables wanted

- Original vector SVG icon per application, built on a shared construction grid.
- PNG exports at 16, 24, 32, 48, 64, 128, 256 and 512 px.
- Symbolic monochrome icon for Linux desktop environments.
- Light and dark variants.
- App-store screenshots and a short brand guideline document.

## Rules

- Recreate; do not trace or embed the reference bitmap.
- Use free or self-made fonts with licenses compatible with the project.
- Do not use Microsoft or any other third-party trademarks in artwork.
