# Fixtures

Reproducible sample files used by tests and benchmarks.

| Directory | Contents |
|---|---|
| `xlsx/` | OOXML workbooks exercising shared strings, styles, formulas, hyperlinks, merges, frozen panes, multiple sheets, tables, drawings, charts and named ranges. |
| `csv/` | CSV files covering delimiters, quoting, encodings, line endings and locale-specific numbers. |
| `vba/` | VBA modules and `.xlsm` workbooks for the compatibility test suite. |

## Rules

- Every fixture must be **original** or come with a license that permits redistribution, documented in a `SOURCES.md` next to it.
- Never commit real customer or personal data.
- Keep fixtures small; large benchmark inputs are generated by scripts in `benchmarks/` from a seed, not committed.
- Name fixtures by what they test, for example `merged-cells-and-frozen-panes.xlsx`.
- Each fixture should be referenced by at least one test or benchmark.
